## Traps found and fixed during implementation

1. **LIVE_RLO clamp kink (the big one).** `selfgrav-frozen` Jacobi first
   failed at p99 6.5e-3. Bisection: dt-INDEPENDENT (7.7e-3 at dt
   0.01/0.005/0.0025), linear in table amplitude (×0.1 amp → 1.25e-3),
   independent of theta, present with the table perfectly static.
   Cause: `liveSample` hard-zeros `amp` for R<LIVE_RLO=0.3 with derivative
   zeroed, while the global solve's inner field arrives with slope
   ~0.5·amp[1]/dr ≈ 1.4e-2 force jump at every crossing — the WKB path only
   squeaked by on its 5× smaller inner amplitude (p99 1.5e-3). Fix in
   `selfgrav.js` edge factor: pin bins 0–1 to exact zero (value AND slope 0 at
   the boundary); lost zone R<0.78 is inside the ILR, outside the study.
   p99 → 2.76e-4 (the full-script rerun reports 4.78e-4 with the settled
   table). Ruled out along the way: hot-loop vs accelSingle mismatch,
   non-rigid time dependence, table mutation, gradient inconsistency.
2. **`Galaxy.liveGain(P, spirOn, barOn)` argument order.** The page first
   called it as `(P, ui.bar, ui.spiral)` → spiral off → gain 0 → the armed
   global table stayed zero (smoke caught it). Always `(P, spirOn, barOn)`.
3. **Q dispersion moments are mass-weighted.** The first closed-loop run
   gated on `minQ 0.03` for EVERY run including the twin — dividing
   `Σ m·vR²` by star count instead of `Σm` underestimates sigR by ~√m
   (~100×). Fixed: `mu = vr1/m0`. Profile then matches the 0.4.0 pre-flight
   (min Q≈2.4–3.0 inner, 8–17 at R=4–6).

## Outcome recorded per acceptance: **(c) unresponsive disk**

Neither "holds the outer disk" (outer never clears the twin) nor
"open-loop only" (the open loop also does nothing) — the measured outcome is
the third one: **the outer disk is unresponsive at Q=8–36**. The limiting
mechanism is the outer disk's own Q, not the kernel: the pre-flight shows the
global term delivering 12% of As at R=4.5 (112× the WKB estimate), and the
closed loop remains fully stable at every gain while the outer band never
leaves the noise floor. What the loop DID buy is a bounded, coherent INNER
enhancement (mid +4.7%, inner +11.8% at g=1, monotone in g at N=40k) with
zero stability cost.

Per plan §7 the global solver therefore **ships as a documented experiment at
default off** (`select#sel-sg` value 0); selecting `global` arms gfb=5 like
the old toggle did, so the inner enhancement is one click away. `galaxy.js`
and the WKB path remain the default and byte-identical. The named lever for a
future outer response (0.6.0 scope): a colder outer disk / sigR(R) profile —
the disk's Q, not the force.
