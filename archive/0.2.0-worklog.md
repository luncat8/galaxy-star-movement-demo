- Narrow-annulus m=2 response at T=150: coherent only R=1.6-3.0 (amp 0.24-0.42),
  random phase beyond R=3.4 (check-arm-profile.js) while the render showed stars
  to R=6.5 — half the visible disk WAS noise.
- Response phase twists -87..+82 deg across CR=2.57 (finding 12/16) — arms break
  at corotation.
- Default speed 0.1 tu/frame ~ 5.5 px/frame at default zoom: strobing = aliasing,
  not physics.
- Reference is calm by construction (pre-aligned ellipse orbits) + nebula/H-II
  render layer + slow motion; its docs admit real orbits are rosettes.
