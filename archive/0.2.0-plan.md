# 0.2.0-plan.md — stability & noise: matching the density-wave reference look

Reference: File:Galaxy_rotation_wave.ogv (beltoforion's Galaxy Renderer).
Goal: keep the honest test-particle dynamics, but get the reference's calm,
persistent, full-disk arms instead of the current granular, breathing look.

## 1. Problem decomposition: what "noisy" is, measured

| # | symptom | measured cause |
|---|---------|----------------|
| N1 | granular "naked points" texture | 4k additive sprites on dark bg; reference uses ~60k stars PLUS a nebula/H-II layer precisely because naked points read as disconnected |
| N2 | strobing / jitter of motion | default speed 0.1 tu/frame x ~55 px/tu = ~5.5 px/frame at default zoom; temporal aliasing, not physics |
| N3 | outer disk is scatter, not arms | narrow-annulus m=2 at T=150: amp 0.24-0.42 with coherent phase for R=1.6-3.0, then 0.02-0.1 random phase for R>3.4 (check-arm-profile.js). But the render shows stars to R=6.5 (thin sampled to 6, thick to 7) — over half the visible disk is genuinely disorganized |
| N4 | arms break / don't connect | response phase twists -87 -> +82 deg across CR=2.57 (check-arm-profile.js; also findings 12, 16): zones either side of CR don't join into one continuous arm |
| N5 | slow breathing/fading of arms | wide-annulus spiral response 0.326 -> 0.190 from settle to T=150, young 0.518 -> 0.415 (check-response.js); separatrix libration bunching (finding 13) makes local contrast pulse |
| N6 | structure diluted by non-disk light | bulge 10% + halo belt 8% + stream 2% + thick 25% rendered at near-equal brightness to the arm-carrying thin/young disk |

Root physical fact (finding 16): steady test-particle response exists ILR->CR only.
No potential tweak tried so far organizes CR->OLR (amplitude scans, envelope tapers
failed). Kinematic alignment shears too: Omega-kappa/2 - Om_p decorrelates neighbouring
apses in ~2-8 tu (R<2), ~20 tu (R=3), ~50-70 tu (R=5) — measured in
experiments/curve-precession.js.

## 2. Why the reference is calm — and what that costs

The reference has three legs we don't:

1. **Arms by construction.** Stars ride fixed-orientation ellipses whose position
   angle advances with radius. Arm crowding exists at EVERY radius at t=0 and never
   breathes, because nothing is being organized — it is drawn. No resonances, no
   capture, no migration, no radial zones.
2. **Rendering layer.** Nebulae (point sprites) plus H-II regions sized by local
   inter-arm spacing hide the point grain; 60k stars; black-body color palette.
3. **Slow, smooth motion** (21 s loop, sub-pixel steps).

Its own docs admit real stellar paths are rosettes, not those ellipses. So we will
not adopt construction as our dynamics — but we can adopt each leg selectively.

## 3. Solution catalog

### S1. Presentation package (kills N1, N2; masks N3, N6) — do first, zero physics risk
- **S1a motion smoothing**: preallocated previous-position buffer, render
  interpolated sub-steps (render dt independent of sim dt); default speed 0.1 -> 0.03.
  Sub-pixel motion, no aliasing; no physics change.
- **S1b diffuse density underlay**: each frame bin disk classes into a coarse grid
  (e.g. 128x128, reuse buffer), box-blur, draw additively under the stars with low
  alpha; optionally render the non-axisymmetric excess only (subtract per-annulus
  mean) so the smooth disk stays subtle while bar/arms glow. This is the single
  biggest calm-look lever; it is exactly the reference's nebula layer.
- **S1c class weighting**: default alpha down for bulge/halo/stream/thick; young
  disk is the hero tracer. Legend unchanged.
- **S1d H-II knots (optional toggle)**: a small fixed population of cloud tracers
  sampled with the young disk; rendered only within a threshold of a spiral-crest
  phase (we have the analytic phase already), size by proximity to crest. They move
  exactly like stars (beltoforion's trick), no spawns, deterministic.
- Gates: existing suite passes; headless PNG A/B (finding 19) at settle vs T=150
  must read visibly calmer; fps budget at 10k unchanged (check-perf).

### S2. Kinematic aligned-ICs ("honest beltoforion", attacks N3, N4 at t=0) — experiment
- Give disk stars a small epicyclic eccentricity e(R) and set pericenter angle
  psi(R) from the same winding law as the potential's spiral, in the pattern frame,
  at the end of settle. Arms then span the full disk at t=0 **by construction of
  the DF**, not by fake rendering — every star still just orbits the fixed field.
- Measured decorrelation says outer alignment decays over ~20-70 tu; inner arms are
  continually re-imposed by the m=2 forcing (ILR->CR), so expect: persistent inner
  structure + a slow unwinding of outer arms over tens of tu. Frame it honestly in
  the UI as the transient grand-design phase; T=150 morphology must not be worse
  than today's.
- Findings 13/17 apply: IC changes don't fix the settle transient; gate median Lz
  and narrow-annulus contrast, not energy slope. Zero risk to EJ gates (ICs only).
- Cost: IC function + re-settle validation. Risk: low (worst case: reject).

### S3. Re-zone the pattern (attacks N3/N4 by moving CR outward) — cheap to try, known trade-off
- Om 0.36 -> ~0.25 puts CR near R=4, ILR near R=1.1: coherent zone then covers most
  of the bright disk. Findings 18 warns: ILR drags toward the bar, bar-frame twist
  must be re-validated in 0.25-wide radial slices; bar and spiral share Om so both
  move together. Also lower Om slows the visible pattern rotation.
- Gate: check-response + bar twist profile + check-arm-profile before/after.
- Risk: medium-low; may fail the bar-x1 gate exactly as Om=0.33 did (finding 18).

### S4. Rejected for this goal (documented so we don't retry)
- **Envelope tapers / amplitude scans for CR->OLR response**: refuted, finding 16.
- **Second pattern speed for the outer disk**: beating, finding 11.
- **Thermostat/cooling**: angular-momentum pump artifact, finding 17.
- **Drag**: collapses inward; wrong for collisionless stars (review 0.1.1).
- **Full N-body self-gravity**: out of scope (cheap, stable, teaching goals).

### S5. SCF-lite self-consistent feedback (attacks N3/N5 at the root) — only if S1-S3 insufficient
- Measure m=2 amplitude+phase per annulus each K frames (diagnostics already do
  this), time-smooth, and feed back as an extra m=2 potential component with
  amplitude = beta*(measured - nominal), saturated and bounded. Pattern speeds stay
  rigid; only amplitude adapts. The wave then feeds itself where forcing alone dies.
- Costs: EJ/Jacobi diagnostics lose their fixed potential — gates must switch to
  shadow runs (finding 3) + no-clumping + median-Lz. Feedback instability is the
  real risk: start beta tiny, saturate at 1.5x nominal amplitude.
- Only schedule after S1+S2(+S3) verdict, and only for the outer-disk gap.

### S6. Micro-fixes bundled anywhere
- spiral zs 0.5 -> 0.65 if vertical scatter still reads (finding 8 trade-off).
- resonance-rings overlay default off (visual clutter reads as noise).
- trails default off already; keep.

## 4. Recommended order

1. **0.2.0 = S1 + S6** (presentation): calms N1, N2, N6 immediately, masks N3/N5;
   no physics gates at risk. Deliverable: visibly quieter render at defaults,
   A/B renders in experiments/logs/.
2. **0.3.0 = S3 then S2** (structure): re-zone pattern; if bar gate fails, revert
   Om and do S2 alone. Success = coherent m=2 amp >= 0.2 out to R~4 at T=150 with
   clean bar twist, arms visibly connecting across CR.
3. **0.4.0 = S5** only if the outer disk still reads as noise after 0.3.0.

Success metric for "matches the reference": headless renders at settle, T=75, T=150
at fixed phase must show two continuous arms from bar ends to R~4+ with contrast
>= 1.5 in every narrow annulus of 1.6-4.0, and no radius band reading as scatter.
