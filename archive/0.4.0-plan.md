# 0.4.0 plan — S5 live m=2 self-gravity (SCF-lite) + stability study

Goal: test whether the disk's OWN measured m=2 response, fed back as a small
self-gravity term, can hold spiral arms outside corotation past the settle
transient. Inside CR the static potential already does this; the measured
failure is at R > ~4 (finding 16: no organized response CR -> OLR at any static
amplitude). S5 is the one lever left that is not a bigger external field: if the
outer disk's response feeds its own forcing, the outer forcing can grow from the
disk itself.

## 1. Why a self-gravity term at all

- A test-particle response to a static m=2 field saturates (finding 16): small
  De + strong forcing = nonlinear overdrive, and beyond CR the response has no
  steady phase to lock onto.
- Real density waves are self-gravitating: the disk's own density enhancement
  contributes to the potential it responds to. That closes the loop and is the
  only mechanism in this model that can make the outer forcing track the outer
  response instead of being fixed by a slider.
- Cheap approximation, no N-body: measure the m=2 Fourier component of the
  sampled disk density in the pattern frame, convert it to a potential with the
  local WKB Poisson relation, add it to the force.

## 2. Physics

### 2.1 Measurement (pattern frame, cylindrical grid)

- Grid: `LIVE_NB = 32` bins, `R = 0.3 .. 8.0`, width 0.240625. Bin fields:
  m=2 moment `c = sum m_i e^{2 i phi_i}`, mass `ms = sum m_i` (grid fields
  `cr/ci/ms`).
- Star masses come from a per-class table (`liveMassTable`): thin-table stars
  (thin + young classes) share `thin.md`, thick stars share `thick.md`; bulge,
  halo and stream contribute nothing (S5 estimates the DISK's own response).
  Sampling without replacement means the shares match the potential's masses.
- Accumulation happens in the hot loop: only when the live term is active, only
  for disk-class stars, using `cos 2phi / sin 2phi` algebra (no `atan2`, no extra
  trig; finding 9). The phasor is consumed by the NEXT substep's force
  (one-step lag, as in any SCF scheme).
- Rotate the moment into the pattern frame (finding 11: one pattern speed):
  `A e^{-i psi}`, `psi = 2 (Om t + p L(R))` with `p = 1/tan(pitch)` and the C1
  `spiralLD` winding law. In that frame a steady arm is a static vector, so
  averaging over R and t suppresses shot noise without smearing the wave.
- Smoothing: Gaussian in bin space with `LIVE_LR = 2.0` bins (sigma ~0.48 in R)
  on the complex phasor, then a one-pole low-pass in time, `tau = 4 tu`
  (`beta = 1 - exp(-dt/tau)`), again on the complex phasor.
- Data mask: completeness `m0/(m0 + LIVE_EFOLD)`, `LIVE_EFOLD = 1.2e-3` column
  density, against `m0 = ms/area`, times a taper `LIVE_EDGE` that goes to zero
  over the first 0.5 and last 1.2 in R, so the grid ends never inject force
  where the grid has no data.

### 2.2 Potential

- `Phi_live(R, phi, z, t) = amp(R) * Z(z) * cos(2 (phi - Om t - p L(R)) - theta(R))`
  with `Z(z) = exp(-z^2 / zs^2)`, `zs = 0.6` (`P.live.zs`).
- `amp(R) = cap * est / (est + cap)`, a soft saturation: growth is smoothly
  damped with no branch, so the inner loop never pays for a check and the
  amplitude can neither run away nor be cut by a hard clip.
- `est = gfb * mask(R) * 2 pi G Sigma2(R) / k`, `Sigma2` = m=2 surface-density
  amplitude = `|phasor| / area`, `k = 2 p / R` (the m=2 radial wavenumber of the
  spiral basis). This is the local WKB Poisson relation; it is a local estimate,
  not the global Green's-function inversion (an FFT/SCF implementation would
  replace this one line and nothing else).
- Phase convention: the m=2 density moment measured as `A e^{i psi}` has its
  crest at `2(phi - psi) = 0`, i.e. at `2(phi - Om t - p L) - theta = 0` with
  `theta = psi`. A density crest must ADD a potential WELL at its own crest, so
  the table stores `theta = psi + pi` — the force is written with a minus theta
  and `cos(2psi + pi) = -cos(2psi)`. Getting this sign wrong makes the feedback
  repel its own arms (measured: an outward median-R drift, an artificial hole in
  the arm zone, `phase(theta) ~ +/-pi` against the measurement).
- `gfb` is the master gain: 0 disables the mode entirely (no masking table, no
  measurement, no feedback).

### 2.3 Force and integrator consistency

- The force is the exact gradient of the potential above:
  `fR = -Z (damp/dR * C + amp * S2 * W)`,
  `fp = Z amp 2 S2 / R`, `fz = -amp C dZ`,
  with `C = c2 cos(bs) + s2 sin(bs)`, `S2 = s2 cos(bs) - c2 sin(bs)`,
  `bs = 2(phi - Om t - p L) + theta` and the local wavenumber
  `W = 2 p dL/dR + dtheta/dR`. `xi/Rc`, `yi/Rc` give the xy components, the same
  algebra as the static spiral term (finding 9 keeps it allocation free).
- Table interpolation must be C1: linear interpolation has a slope that is NOT
  the interpolated derivative, so the analytic force would differ from the
  gradient of the potential (measured 4e-4 relative — 4% of the live force's
  curvature term) and the leapfrog would pay for it (finding 1).
  Use Catmull-Rom for value+derivative of both `amp(R)` and `theta(R)`.
- Ordering inside `step()`: half-kick, drift, `computeAccel` (which refreshes
  the live table from the moment accumulated during THAT accel pass, then uses
  the previous substep's table for the new force), closing half-kick. One
  explicit lag, no sub-stepping of the measurement.
- The live term is evaluated only when `gain > 0 && ramp > 0 && R < LIVE_RHI`;
  `P.live.freeze` reuses the existing table (a frozen live potential is a
  single-pattern static field, so a Jacobi integral exists and can be gated).

### 2.4 Stability levers (the prereq the next-step suggestion asked for)

1. Soft saturation at `cap = 0.02` (deep in the linear regime: the live
   potential shifts particle energies by less than 1e-3 in absolute terms).
2. Low-pass `tau = 4 tu` in the pattern frame: the feedback cannot respond
   faster than an epicycle-free pattern time.
3. Completeness mask + edge taper: no force where there is no measured density
   (the grid-end hole would otherwise act like a radial cutoff — finding 1).
4. Radial smoothing: shot noise in the moment is suppressed before it reaches
   the potential.
5. `liveGain = gfb * live.g * spiral.g * (1 - bar.g)`: the live wave rides the
   spiral pattern speed and fades out when the bar is on, because two pattern
   speeds beat and grind the disk (finding 11). Toggling the mode fades its gain
   over `P.fade = 8 tu` like the other modes.

## 3. Parameters (defaults)

    P.live = { gfb: 0, g: 1, cap: 0.02, tau: 4, zs: 0.6, freeze: false }

`gfb = 0` is the SHIPPING default: the calm preset must not change by default,
and a study decides whether the mode earns a nonzero default (see 5). Grid and
smoothing constants stay module-private (`LIVE_NB`, `LIVE_RLO/RHI`, `LIVE_LR`,
`LIVE_EFOLD`, `LIVE_EDGE`) — they are numerical properties of the measurement,
not physics knobs.

## 4. Validation suite

- `check-live-mode` (new, study gate): per gain, settle then sample every 5 tu
  to T=150. Bands 1.0-2.5 / 2.5-4.0 / 4.0-5.0 / 4.5-5.5, mass-weighted m=2
  phasor in the pattern frame, disk classes only. Reports the amplitude of the
  mean phasor over T=75-150 (coherent amplitude: keeps a steady wave, averages
  incoherent response), the per-sample p50/p80 and the duty cycle (fraction of
  samples above 0.08), plus the narrow-bin unweighted profile for comparability
  with `check-arm-profile`. Also prints the live table's own phase coherence
  (`|mean phasor| / mean |phasor|` over the window) at R ~ 2.0, 3.1, 4.5, and
  the saturation trajectory of `amp(t)`.
- Gates: `liveAmpMax <= cap` (no runaway); radial histogram peak/mean of the
  first run must not grow > 1.25x (no clumping, `check-no-clumping` style);
  median R drift < 10% over 150 tu (no systemic inflow —
  `check-drag-collapse` style); the inner band's coherent amplitude must not
  drop below 0.7x the `gfb = 0` run (no harm where forcing already works).
- `check-gradient`: the live force must equal `-grad Phi_live` within 1e-4
  relative and 1e-7 absolute, on a synthetic frozen table, with the measured
  `dtheta/dR` included in the wavenumber.
- `check-jacobi`: with `P.live.freeze` and `gfb = 1`, the Jacobi integral at
  `om = spiral.om` must stay inside the standard single-pattern gates
  (p99 < 2e-3, max < 1e-2) over 60 tu. This tests the live FORCE, not the
  feedback loop (while the table updates, the pattern does physical work).
- Bit-exactness: `gfb = 0` must reproduce the legacy trajectory bit for bit
  (`P.live.g` cannot leak into any force path).
- `smoke-page`: the live toggle must arm a default strength, the slider must
  reach `P.live.gfb`, the feedback table must become nonzero, and the HUD must
  report the mode, all headless.
- `check-perf`: the live mode must be measurably cheap when off. Budget: the
  moment accumulation plus the per-star live force may not cost more than ~1.5x
  of the live-off substep.

## 5. Acceptance and decision rule

The mode ships as the default only if it visibly holds arms beyond R ~ 4 past
the transient, i.e. the outer band (4.0-5.0) coherent amplitude at T=75-150
grows clearly above the `gfb = 0` value while the inner band is unharmed and
every stability gate passes. Otherwise the mode ships OFF as a documented,
gated experiment (page toggle + slider), and the study concludes with the
limiting mechanism, so the next plan starts from measurements instead of hope.

## 6. Page integration

- `Field` slider `live m=2 g` (0..10, `P.live.gfb`) and overlay checkbox
  `live m=2 (S5)`; dragging the slider arms the mode, and enabling the mode with
  a zero amplitude sets a mid default, so the control is never a no-op.
- Key `m` toggles the mode; the keys line in the approach text documents it.
- HUD: while the live mode is active the Jacobi readout is `n/a` (the profile is
  re-measured at a fixed pattern speed, so no invariant exists — same rule as a
  mode fade), and the warning line says so; with the bar on it says the live
  term is fading out.
- Journal entry in `index.html`, worklog in `archive/0.4.0-worklog.md`.

## 7. Out of scope

- Global (FFT/Green's function) self-gravity: keep the local WKB relation as the
  single replacement point; a global solver is the natural 0.5.0 step.
- m=1/m=4 and bar feedback: the live term rides the spiral pattern speed only.
- Spiral-pattern-speed coupling to the measured response, energy feedback, or
  pattern-speed drift: pattern speed stays a fixed parameter.
